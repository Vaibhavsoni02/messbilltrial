# Hostel Mess Bill Calculator

**Created:** 2023-03-19

## Problem
Splitting hostel mess expenses across students was manual and error-prone.

## Solution
A Streamlit tool that takes expense totals and student lists, then calculates each person’s bill.

## Outcome
Faster, clearer monthly mess bill splits with less spreadsheet math.
